    A plausible patch is not enough.

    Hidden deterministic tests check the submitted patch on a clean project copy. Task certification rejects both the buggy baseline and an incomplete repair, and accepts the reference repair.

    Seeing the bug is only the start.

    Replay reveals the next bug.

    In Letter Arc, an initial CSS edit exposes a second defect: revealed tiles turn dark mid-animation. These two frames show that replay defect. Further edits pass all 24 browser checkpoints; the final repair is not pictured.
